# M0 断層上の震源選択 UI 確認記録

更新対象：M0 モック（震源自由選択）

## 手動操作とヘッドレスブラウザの通し確認

- 断層上のクリックで最短位置に吸着すること（約29.7%）
- 震源マーカーを断層沿いにドラッグできること（約88.3%に移動）
- 位置スライダーで任意値（36.8%）を設定できること
- 指定値と代表演示区間の対応（36.8%=西部、50.0%=東部）
- 震源位置が観察画面および結果画面に保持されること
- 東部代表ケースの再生に切替できること
- 29分には30分のイベントがなく、30・31分には当該イベントが表示されること（Δt=1分）
- RP不足と現実性制約を異なる警告で示すこと
- 390px幅で位置設定が表示されること
- JavaScriptランタイムエラーがないこと

確認手法：Chromium + Playwright。HTML/CSS/JSをページにインライン投入したテスト。
M0は固定演示であり、断層位置に応じた物理計算は未実装。
