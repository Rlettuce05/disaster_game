# M0 代表プレイの画面演示台本

## ケースA：西部震源

1. タイトルから「都市の分析を始める」を選ぶ。
2. 西部給水センターを選択。消防がその水道供給に依存することを確認する。
3. 災害条件へ進み、架空断層の西端から約12.5%の位置を地図クリックまたはドラッグで指定し、M6.5（35 / 60 RP）に設定する。
4. 地震を発生させる。1分刻みの再生・ステップ送り・時間バー操作（例：00:29→00:30→00:31）を確認し、次を観察する。
   - 00:30 給水センターの損傷
   - 01:00 消防用水不足、住宅地区の火災
   - 01:30 消防隊の派遣（受けた火災通報を判断根拠として表示）
   - 02:00 消火活動が制約される
   - 03:00 火災が拡大
   - 04:00 道路閉塞、市が迂回路確保を指示
   - 06:00 医療搬送の遅延
5. 結果へ進み、イベントの原因欄と派生欄を確認する。

## ケースB：東部震源

1. 「条件を変えて再挑戦」を選択する。
2. 架空断層の約85.5%の位置を指定し、M6.5で演示を開始する。
3. 電力設備の損傷、病院停電、非常用電源稼働、送電復旧、医療機能維持を観察する。
4. 結果画面で西部ケースと比較する。

## エラー演示

- M7.3 は75 RPとなり、使用可能60 RPを超えるため実行不可。
- M8.2 は仮の断層モデルの上限 M7.5 を超えるため実行不可。
- これらは説明用の**仮規則**であり、学術的な推定ではない。

## 注意

時刻、稼働率、結果、スコア、因果関係はM0用に人手で構成された演示データです。

## 時間刻みの検収追加

- Δtは1分。00:29では00:30の施設損傷イベントはまだ出ず、00:30で表示される。
- 00:31で新イベントは発生せず、都市状態は00:30の定義値のままとなる。
- 06:00で再生終了し結果分析へ進める。

## 自由震源選択の検収追加

- 断層線の任意位置をクリックすると震源マーカーが移動する。線から外れた位置へは配置できない。
- マーカーをドラッグすると架空断層に沿って連続移動する。スライダーでも0〜100%を指定可能。
- 49.9%以下では西部代表ケース、50.0%以上では東部代表ケースが再生される。50%境界はM0専用の演示切替点。
- 任意の位置（例：36.8%）で実行すると、観察地図および結果画面に36.8%が保持される。被害結果は西部代表の固定データである旨が表示される。
- 時間刻みは従来のΔt=1分を維持する。
