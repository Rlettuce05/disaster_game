# M0 画面遷移・検収メモ

## 主な遷移

```
スタート → 都市分析 → 災害条件設定 → 演示再生 → 結果分析
                                   ↑                 │
                                   └────再挑戦───────┘
```

- スタート：ゲームの目的、M0の限界とシナリオの説明
- 都市分析：施設やインフラ接続を確認し、次の条件設定へ
- 災害条件設定：架空断層上の任意位置とダミーのマグニチュード選択
- 演示再生：Δt=1分のクロックで固定された時系列データを再生し、都市の被害・対応・都市機能推移を表示。新イベントがない時刻は直前の状態を保持
- 結果分析：イベントごとの原因と派生先、ケース比較、評価方針の演示、再挑戦（完了した試行だけ表示）

## UIの責任境界

- プレイヤーは二次被害を直接発生させない。
- 都市側の行動はイベントデータによる演示であり、都市AIの実行結果ではない。
- RPの演示消費、断層モデル上限、終局スコアは本番仕様ではない。
- 画面内の架空データ表示を継続する。

## M0検収手順

- M0-01: 西部で開始し、時刻06:00まで観察、結果分析、再挑戦、東部へ切替
- M0-02: UIから指定できるのは地震位置と規模のみと確認
- M0-03: 西部の水道→消防→交通→医療の経路と、東部の非常用電源・復旧の対策を確認
- M0-04: 起動画面・観察画面・結果画面でダミーである旨が明示されていることを確認
- M0-05: `docs/m1-questions.md` に未検証事項があることを確認

本モックの検収は画面構成・ユーザー体験の合意です。ゲームとしての面白さや災害モデルの正しさを証明するものではありません。

## M0震源位置指定（追加）

「条件設定」のマップに架空断層ポリラインを描画する。プレイヤーは断層上をクリックまたは震源マーカーをドラッグでき、右側のスライダーで位置を調整できる。位置指定の自由度と災害計算の有無は別に扱う。M0で位置に応じた実シミュレーションは実装しない。現在は線分上の相対位置で西部・東部の固定演示を切り替える。選択位置は経過観察・結果にも引き継ぐ。

## Issue #2〜#6 対応による補足

- 再生中の選択イベント詳細は、現在時刻までに発生した後続イベントのみ表示する。結果分析画面では全因果イベントを確認可能。
- 進行中に`app.innerHTML`を毎分更新しない。時刻・スライダー・都市状態・ログ等の可変部だけを更新し、ログスクロールと操作フォーカスを維持する。
- 結果へ進むにはその試行を開始し、06:00まで到達する必要がある。再挑戦時は結果アクセスを再びロックする。画面を戻って設定を変更しても、過去の試行結果は**実行時の震源位置を保持**して表示する。
- 被害原因と都市側の緩和策を分離する。緩和を試みた対応は`context`として関連を示せるが、特別な根拠がなければ被害拡大の`causes`には入れない。
- 結果の深さは有害イベント（hazard / damage / cascade）のみの最長有向経路の**因果辺数**。波及範囲は途中で稼働率が100%未満になった系統数。RP効率は**固定演示スコア / 消費RP**であり、採点式から点数を算出したものではない。
